Source: Devpost Slack Agent Builder Challenge official overview, resources, and rules inspected on 2026-06-13.

## Eligibility

- India is explicitly included in the eligibility area.
- Entrant must be 18+ or age of majority in jurisdiction.
- Teams may have up to 4 eligible individuals; this project is currently working solo.
- Exclusions include current/recent Salesforce/Hackathon entity employees, judges, government employees/officials, and conflict-of-interest cases.

## Required Technologies

Project must use at least one, and SlackSync will use all three:

- Slack AI capabilities / Agent Builder.
- MCP server integration.
- Real-Time Search API.

## Tracks

Primary target: New Slack Agent.

Secondary prize alignment:

- Best UX.
- Most Innovative Slack Agent.
- Best Technological Implementation.

The Organizations track requires Slack Marketplace submission before deadline and Slack App ID. Treat that as a stretch only if product and marketplace readiness are real.

## What To Submit

- Project track.
- Text description covering features and functionality.
- Demo video under 3 minutes, public on YouTube, Vimeo, Facebook Video, or Youku.
- Video must show the working project on the intended device/platform.
- Architecture diagram.
- URL to Slack developer sandbox.
- Test access for `slackhack@salesforce.com` and `testing@devpost.com`.
- Slack App ID for Organizations track if pursued.

## Judging Criteria

All equally weighted:

- Technological Implementation.
- Design.
- Potential Impact.
- Quality of the Idea.

## Official Resource Notes

Devpost resources emphasize:

- Join Slack Developer Program to unlock the free sandbox.
- Claim/use Slack Developer Sandbox as build and demo workspace.
- Use `slack create agent`, Agent Builder templates, Bolt SDK, Block Kit, MCP, and RTS docs.
- Build a real Slack workflow, not a generic chatbot.
- Make first 60 seconds of demo count; judges spend around 5-7 minutes per project.

## Human / Account Blockers

- Slack Developer Program signup still needs the user's PIN/ZIP code, Salesforce personal-data transfer/privacy consent, and CAPTCHA.
- Slack sandbox claim depends on successful Developer Program signup.
- Final Devpost submit remains human-reviewed unless explicitly authorized at the end with all statements truthful.
